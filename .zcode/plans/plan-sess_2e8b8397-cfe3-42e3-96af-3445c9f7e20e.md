# Rombak Total Flappy Bird → Neon/Cyber Edition

## Ringkasan
Rewrite penuh `src/app/game/flappybird/page.js` (329 baris → ~450 baris) menjadi game neon/cyber yang konsisten dengan identitas portfolio (dark bg, lime accent, Tech HUD). Satu file, zero new dependencies.

## Yang Dihapus
- Bird lingkaran kuning polos
- Pipa kotak hijau polos
- Background flat `#87CEEB`
- Game loop buggy (useEffect re-run setiap state change via `[started, gameOver]` deps)
- Tanpa best score

## Yang Baru

### 1. Visual (Canvas 2D, neon/cyber style)
- **Background**: dark gradient + animated grid parallax (garis neon bergerak ke kiri)
- **Bird**: bentuk diamond/segitiga neon dengan `shadowBlur` glow, trail partikel, rotasi berdasarkan velocity (nose up saat naik, dive saat turun)
- **Pipes**: neon outline dengan glow `shadowBlur`, gradient fill tipis, cap di ujung
- **Ground**: neon strip bergerak di bawah
- **Particles**: burst saat skor (titik neon) + explosion saat game over
- **Screen shake** saat collision

### 2. Gameplay
- Physics: gravity + jump, bird rotation mengikuti velocity
- Difficulty: gap menyempit & speed naik per 5 skor (capped)
- Spawn interval dinamis
- Collision detection akurat (hitbox lebih kecil dari visual = forgiving)

### 3. State Management (fix bug lama)
- Game state (bird, pipes, frame) di `useRef` — tidak trigger re-render
- React state hanya untuk UI: `score`, `gameState` (`idle`/`playing`/`dead`), `bestScore`
- Single `useEffect` dengan `[]` deps, game loop via `requestAnimationFrame` dengan ref flag
- Input: Space / ArrowUp / Click / Tap

### 4. Best Score
- `localStorage` key `flappy_highscore` (pattern sama dengan snake game)
- Tampilkan "Best: X" di UI

### 5. Sound (Web Audio API, zero files)
- `AudioContext` prosedural: blip saat jump, ding saat score, thud saat game over
- Toggle mute button (persist ke localStorage)

### 6. Theme Integration
- Pakai `useTheme()` untuk `themeColor` → warna neon bird & glow mengikuti accent user
- `isDark` toggle untuk adjust opacity/background

### 7. UI (React + framer-motion, konsisten dengan game lain)
- Start screen overlay dengan instruksi
- Game over overlay dengan score + best + restart button
- Score display neon glow di atas canvas
- Back to game menu (pattern sama: fixed top-left glassmorphism link)
- Mute toggle top-right
